3. Funding-Facing Summary (/funding/summary.md)
Project Description

eutube is an early-stage proposal for a bot-resistant, privacy-preserving European media infrastructure designed to strengthen democratic resilience and transparency in digital communication.

It addresses structural failures in existing large-scale platforms by focusing on architecture, governance, and user agency rather than content-level enforcement alone.

The Problem

Current dominant platforms:

incentivise engagement over accuracy

are vulnerable to automated and coordinated manipulation

rely on opaque algorithmic control nThese issues undermine public trust and democratic discourse.

The Approach

Human-first participation models

Explicit AI transparency and labelling

Bot resistance by behavioural design

Jurisdictionally coherent deployment

Governance treated as infrastructure

The project prioritises system integrity over growth metrics.

Why Europe

Europe provides:

a mature digital rights framework

strong privacy and data protection norms

public funding mechanisms for democratic infrastructure

The project is aligned with European digital sovereignty and media pluralism objectives.

Current Status

Public concept and architecture defined

Governance and jurisdictional scope documented

Early technical work underway in related semantic and verification systems

This stage is intended to support:

partnership formation

pilot funding

critical review and refinement

Funding Intent

Funding would support:

prototype development

security and threat validation

governance formalisation

limited-scope pilot deployment

The project is structured to remain compatible with public-interest or cooperative ownership models.

Closing Note

These documents are intentionally public and provisional.

They exist to:

establish intent

invite scrutiny

enable informed collaboration

Revisions will be documented transparently as the project evolves.
